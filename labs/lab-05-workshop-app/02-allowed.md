# Allowed research

Kit `network.allowedDomains` lets the proxy reach those hosts. Type this in the Host terminal (or click Run):

```bash terminal-id=host
Research Kristiyan Velkov — read kristiyanvelkov.com for bio and books, check leanpub.com for publications. Summarize what you find.
```

Both hosts should return content. The agent is still inside the VM — the host proxy evaluates each request against the kit rules.
